# P3 – Private neural voice and motion quality teaser

Goal: Compare a **30–45-second English quality sample** against the earlier
9:31 offline eSpeak slideshow, without introducing a production renderer.

This uses existing original 2026 Ozone Explainer source metadata, five original
P3 SVG scenes, gentle 1.0–1.11 camera zooms, short cross-fades, and an offline
English neural voice generated by **Piper 1.8.0**.

- Model: `en_US-lessac-medium.onnx` from
  `rhasspy/piper-voices` at commit
  `b145f2ac26522d6a2ccde0164b7b0e48b1e3199c`.
- Exact model SHA-256:
  `5efe09e69902187827af646e1a6e9d269dee769f9877d17b16b1b46eeaaf019f`.
- Piper engine is GPL-3.0-or-later. Voice model and training data have
  separate licenses; verify them before redistribution.
- Model size: approximately 63.2 MB. Model and config are **never committed**.
- No external TTS service, accounts, paid usage, outside footage or auto upload.

The short demo uses a freshly phrased, fixed English narration rooted in the
existing man-curated science sources. It is not a dynamically generated news
episode. Rights/editorial/publication values remain denied.

## On a disposable CI runner

The workflow creates a temporary Python venv, installs `piper-tts==1.8.0`,
fetches the pinned voice files, checks the model SHA-256, synthesizes speech,
rasterizes P3 SVGs and encodes H.264/AAC with FFmpeg. It verifies actual MP4
duration (30–45 seconds), codecs and size; finally deletes all temporary
media. No artifacts or uploads are retained.

## Optional VPS private playback after CI acceptance

Use a private Python virtual environment for `piper-tts==1.8.0` and download
the two pinned model files **only when you choose to run this**. Environment
variables supply paths for the interpreter and model:

```bash
CI=false GITHUB_ACTIONS=false \
  VNS_QUALITY_TEASER_APPROVED=PRIVATE_REVIEW_ONLY \
  VNS_PIPER_PYTHON=/home/ap/.local/share/vns-piper-venv/bin/python \
  VNS_PIPER_MODEL=/home/ap/.local/share/vns-piper-voices/en_US-lessac-medium.onnx \
  node scripts/vps_p3_neural_motion_teaser.mjs --save-local
```

This explicitly authorized local mode is restricted to the `ap` user,
writes only to private `/home/ap/videonews-previews/`, and never uploads,
publishes, modifies Redis or starts a service. Do not download or install
Piper system-wide; use the isolated venv. The live app and full 8–10 minute
episode remain untouched.

**The quality of the voice is subjective.** Passing a technical test does not
establish broadcast-level speech or visually rich news footage.
